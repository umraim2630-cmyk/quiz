# Kuchikomi Quiz — 口コミで学ぶ企業・業界研究アプリ

社員口コミデータを教材に、**クイズ形式で企業研究・業界研究**ができる就活生向けアプリのプロトタイプです。
口コミサービス本体の課題（新卒会員の少なさ／利用が内定後に偏り入社後ギャップが発生／新たなスカウトチャネルの不足）に対し、
「就活前の学習体験」と「口コミ由来の内部分析」「クイズ実績起点のスカウト」で応えることを狙います。

## コンセプト

- **口コミデータで“内側”を見せる**：外部情報（IR・財務）だけでなく、数千件の口コミを要約したサマリー、
  レーダーチャート、働きがい・組織文化・働きやすさなどの項目別スコアを可視化。入社後ギャップを就活前に減らす。
- **クイズで自然に企業・業界理解が深まる**：習熟度に応じて難易度が上がり、繰り返し正解でクリア。達成率が積み上がる。
- **クイズ実績を起点にスカウト**：既存サービスとは別の新しいスカウトチャネル。返信にはウェブ履歴書登録が必須。

## 実装した機能

| 要件 | 実装 |
| --- | --- |
| 会員登録／本体サービスからのログイン | ログイン画面（「本体サービスでログイン」＝SSO想定 / 「新規会員登録」の2モード） |
| 企業研究・業界研究のクイズ | 実在企業5社・業界5分野、全60問の問題バンク（各対象6問） |
| 習熟度に応じて難易度が上昇 | マスター率に応じて解放難易度が Lv2→3→4→5 と段階解放（`unlockedDifficulty`） |
| 繰り返し正解でクリア／達成率 | 連続2回正解でマスター。対象ごと・全体の達成率を可視化 |
| 間違えた問題だけを繰り返す | 復習キュー（対象横断の「間違えた問題だけ」モード） |
| 高難易度で財務情報を題材に | Lv4・5 は営業利益率・1人あたり利益などを問う財務問題（💰） |
| 口コミの内部分析表示（最重要） | 企業詳細に AI要約サマリー・レーダーチャート・項目別スコア・良い点/課題 |
| スカウト＆メッセージ（履歴書必須） | スカウト受信箱＋スレッド。返信はウェブ履歴書の登録完了で解放 |

## 技術スタック

- React 18 + TypeScript + Vite
- ルーティング：React Router
- レーダーチャート・アイコン：依存ライブラリなしの自作SVGコンポーネント（`src/components/RadarChart.tsx`, `src/components/Icon.tsx`）
- 状態・進捗：React Context + localStorage による永続化（`src/context`, `src/lib/storage.ts`）

> **データについて**
> - 対象企業は実在の5社（トヨタ自動車・三菱UFJフィナンシャル・グループ・ファーストリテイリング・NTTデータグループ・ベイカレント）。
> - 財務データは各社公表の決算資料に基づく概数（トヨタ/NTTデータ/三菱UFJ: 2025年3月期、ファーストリテイリング: 2025年8月期、ベイカレント: 2025年2月期）。
> - 口コミサマリー・スコア、スカウトはプロトタイプ用の**サンプルデータ**です。実サービスでは口コミ本体のAPI／DBから集計・要約する想定です。

## 開発

```bash
npm install
npm run dev      # 開発サーバ (http://localhost:5173)
npm run build    # 型チェック + 本番ビルド
npm run preview  # ビルド結果のプレビュー
```

## ディレクトリ構成

```
src/
  components/   # RadarChart, ScoreBars, Layout
  context/      # AppContext（認証・進捗・履歴書・スカウト）
  data/         # companies / industries / questions / scouts（ダミーデータ）
  lib/          # quizEngine（適応型出題・達成率・復習）, storage
  pages/        # Login / Dashboard / QuizSelect / QuizPlay / CompanyDetail / IndustryDetail / Resume / Scouts
```
