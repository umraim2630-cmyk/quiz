# BizQuiz — クイズで身につく企業・業界研究アプリ

上場企業を対象に、**初級・中級・上級の段階式クイズ**で企業研究・業界研究ができる月額制アプリのプロトタイプです。
就活生・転職活動者・若手ビジネスパーソン・営業/コンサル・新入社員研修・株式投資家を想定ユーザーとしています。

## 実装した機能（要件対応表）

| 要件 | 実装 |
| --- | --- |
| 課金機能（月額980円） | 登録→プラン提示→カード入力のペイウォールを実装。未課金では本体にアクセス不可。設定画面で契約状況の確認・解約が可能（デモ決済。実際の請求は発生せず、本番はStripe等の決済代行と連携する想定） |
| 企業クイズ（級×編の構造） | 初級/中級/上級 × 各5編×10問（全150問）。級・編ごとにクリア率をメーター表示 |
| クリア条件 | 同一問題に**2回連続正解**でクリア。間違えると連続正解数はリセット |
| 級の解放 | **前の級を全問クリアしないと次の級に進めない**（設定画面にデモ用の一括クリア操作あり） |
| 出題モード | 全問題 / 間違えた問題だけ / クリアした問題だけ |
| 解説 | 正解・不正解・タイムアップ後に解説を表示 |
| 回答時間 | **1問10秒**。カウントダウンバー表示、**残り3秒で赤色・明滅の緊迫演出**（`prefers-reduced-motion`対応） |
| ランダム出題 | 企業ごちゃまぜ / 企業内ごちゃまぜ（1社の全級から）/ 級内全編ごちゃまぜ |
| 業界クイズ | 企業クイズと同一ルール（5業界 × 3級 × 10問 = 全150問） |
| 練習機能 | クイズ単位のブックマーク機能 + ブックマークだけの練習。**練習の正誤はクリア率に影響しない** |
| お気に入り機能 | 企業 / 業界 / クイズ（編）単位のお気に入り登録。お気に入りだけのクイズ出題（テスト・練習） |
| 進捗確認機能 | 完全クリアした企業の表示（全級制覇バッジ）、**自分が指定した企業合計のクリア率** |
| トンマナ | ビジネス系ブルー基調のモダンUI（SVGアイコン・メーター・カードデザイン） |

## 画面構造（要件の構造に対応）

```
ログイン / 新規登録
サブスクリプション（月額980円・デモ決済）
ホーム
├ 企業クイズ ─ 初級/中級/上級 ─ 編一覧（テスト・間違いのみ・クリア済みのみ・練習・ごちゃまぜ）
├ 業界クイズ ─ 同上
├ お気に入り（特定企業 / 特定業界 / 編単位、お気に入りだけのクイズ）
├ 進捗率（全体・級別・完全クリア企業・指定企業の合計クリア率）
└ 設定（アカウント情報 / プラン・解約 / デモ操作 / ログアウト）
```

## データについて

- **企業情報は本番では外部サービスのAPIから上場企業全社を取得する想定**です。`src/data/` はそのAPIレスポンスを模したモック層で、プレビューではサンプル5社・5業界を同梱しています（数値は公表資料に基づく概数）。
- クイズは企業・業界マスタから**テンプレートで自動生成**しています（`src/lib/questionGen.ts`、全300問）。API連携後は取得データから同じ仕組みで全上場企業分を生成できます。
- 正解の選択肢は表示時にシャッフルされます。

## 技術スタック

- React 18 + TypeScript + Vite / React Router（HashRouter）
- 状態・進捗: React Context + localStorage（本番はアカウント基盤・DBに置き換え）
- アイコン・メーター: 依存ライブラリなしの自作SVGコンポーネント

## 開発

```bash
npm install
npm run dev      # 開発サーバ
npm run build    # 型チェック + 本番ビルド
npm run preview  # ビルド結果のプレビュー
```
